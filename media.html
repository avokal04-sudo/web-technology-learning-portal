1. Adding an Image

HTML uses the img element to display images on a webpage. The src attribute specifies the image location, while the alt attribute describes the image.

Note: If the image does not appear, check your Internet connection or replace the image URL with a local image file.

2. Image as a Hyperlink

An image can also work as a hyperlink. Click the image below to visit W3C.

3. Adding Video

The HTML video element allows us to display video files directly inside a webpage. The controls attribute provides play, pause and volume controls.

4. Adding Audio

The audio element allows us to play sound files inside an HTML document.

5. Embedded Webpage

The iframe element displays another webpage inside the current webpage.

This iframe displays your own index.html page. All three HTML files must be in the same folder.

6. How Media Loads on a Webpage

  1. The browser reads the HTML document.
  2. It identifies the image, audio and video resource URLs.
  3. The browser sends HTTP requests to obtain those resources.
  4. The web server returns the requested resources.
  5. The browser displays the media or provides playback controls.
